# 포트폴리오 참고 자료 (예전 버전)

이 폴더에는 예전에 만든 포트폴리오 자료(PDF, 이미지, 문서 등)를 넣어 두세요.
`portfolio.html`을 만들 때 참고만 하는 용도입니다.

- 이 폴더 안의 파일은 `.gitignore`에 등록되어 있어 GitHub에 올라가지 않습니다. (이 README만 올라갑니다.)
- 폴더 이름이 `_`로 시작하므로 GitHub Pages(Jekyll)도 이 폴더를 공개하지 않습니다.
- 홈페이지에 실제로 쓸 이미지는 정리한 뒤 `images/games/{game-id}/`로 옮겨서 쓰세요.
